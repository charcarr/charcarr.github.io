Can you hire an AI agent?

A commentary on how we speak about agents

Charley Carriero
September 27, 2026

It’s been a tremendous year for AI agents. Perhaps like me, you’ve found it hard to appreciate all that has happened. For example:

The coding agents of last year were helpful for writing software unit tests. The tests they wrote failed a lot, but working with them was a welcome improvement.

The coding agents of this year have convinced me and many other software engineers that we will not be coding by hand anymore. Many of us already aren’t. How we build software is changing wildly fast.

As the capabilities of agents leap ahead, it feels natural to anthropomorphize them. Though I wonder if we should. Saying that you’ve hired an agent or are managing a team of agents feels misleading to me. Maybe I’m wrong, or slow to adapt to this linguistic change. I’m happy to be convinced otherwise, but until then, here’s what has helped me make up my mind.

Briefly, agents

Agent is a word that we give to a person or system that is able to act on your behalf. This person or system (your agent) acts on your behalf to achieve some agreed-upon objective. For example, you hire a travel agent to plan a holiday.

We often work with computers to achieve agreed-upon objectives, but until recently, we would rarely say that they’re acting on our behalf. This is because if you have to tell something explicitly what to do, it’s not acting on your behalf, it’s acting exactly how you told it to. To further the example, you can hire a travel agent to book your holiday, and use a computer program to send your out-of-office auto-replies. But no one calls your out-of-office bot agentic.

What’s happening now is that for the first time, thanks to generative language models, we’re able to write programs that don’t just follow a list of instructions, they instead decide what the instructions should be, and then execute them.

AI vs AI agents

So is the generative language model the agent?

A generative language model predicts the most likely next piece of text, based on the enormous amount of text it was trained on. Out of the box, language models are very good at language tasks: translating, summarizing, rewriting. You don’t need to build an agent to accomplish any of these tasks.

What’s interesting is that even for language-esque tasks, like counting letters, generative language models don’t perform reliably.

There are 2 r’s in strawberry, right? You’re absolutely right, there are 2 r’s in strawberry.

Models don’t read text letter by letter, and they also can’t count. This isn’t intuitive if you think of a model as being ‘intelligent’. But if you think of a model as a text predictor, it’s easier to imagine why it won’t know the current time. Computer programs, however, are very good at counting and knowing the current time. This is why we started building agents.

A summary: picture the model–agent relationship in fashion. AI is very similar.

Agents exist to help models do work.

Without an agent, a model can’t get the important connections that it needs to succeed.

Making agents

There’s no single or defined way to build an agent, but there are common building blocks. It is simply a computer program at the end of the day.

We’re still learning a lot about how to optimally build agents. In doing so, I’m even learning a lot about how I like to interact with them. I think while we’re experimenting, the language we use around agents is especially important. Not for the sake of linguistics, but really just so that we can learn from each other.

Given the above, we return to our discussion on how we speak about agents. Perhaps the following now have a different meaning.

“I’m managing a team of agents.”

What happens: I run several programs in parallel to achieve my goal.

“My agent learned to do X.”

What happens: I edited its instructions, or told it to write a note that it can read next time. The model itself hasn’t changed.

“My agent booked me a train.”

What happens: The model replied with a request to use the booking tool, and the program ran it.

And finally,

“I hired an AI agent.”

What happens: I’m using a computer program to automate some work. The program runs a model in a loop to get the task done.

So, can you hire an AI agent?

For me, I would say no. You can work with one. Which I think is already a big step up from what we can say about traditional software.
Now, if you want to tell your agent it’s hired, I have no objections.
